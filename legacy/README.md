# Наследие (Legacy)

Здесь лежат исходники двух проектов, которые предшествовали «Мониторингу техники (ЕТС)».
Они **не используются** текущим приложением и оставлены только для истории.
Обе папки можно безопасно удалить, если они больше не нужны.

## `legacy/map/` — Проект 1: Карта-редактор

Веб-приложение (Vite + Leaflet + Geoman) для редактирования улиц, дворов и маршрутов техники.
Также содержит ранний Node-прототип бота (`bot.js`, `estp-bot/`), который собирал данные с ЕТС
и формировал отчёт. От этого прототипа отказались в пользу Python-версии.

**Статус:** заброшен (последние изменения — октябрь 2026).
**Зависимости:** `npm install` внутри папки.
**Запуск:** `npm run dev` (для редактора) или `node bot.js` (для прототипа).

## `legacy/bot/` — Проект 2: Старые парсеры ЕТС

Скрипты для разовой выгрузки маршрутов и геозон из ЕТС:
- `parse_ets.py` — парсинг одного маршрута.
- `parse_all_routes.py` — парсинг всех маршрутов.
- `parse_geozones.py` — парсинг геозон.

Результаты выгрузки: `ets_route.json`, `ets_all_routes.json`, `ets_geozones.json`.

**Статус:** заброшены (ноябрь 2026). Пути внутри скриптов указывают на `bot/`, поэтому
для запуска их нужно править или запускать из корня проекта.
